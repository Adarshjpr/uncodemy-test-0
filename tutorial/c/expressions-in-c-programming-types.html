Expressions in C Programming - Types of Expressions in C ( With Examples )

What is an Expression?

An expression is a combination of variables, constants, and operators that evaluates to a single value.

Types of Expressions

  • Arithmetic expressions — e.g. a + b * c
  • Relational expressions — e.g. a > b, evaluate to true/false
  • Logical expressions — e.g. a > b && c < d
  • Bitwise expressions — e.g. a & b
  • Conditional (ternary) expressions — e.g. a > b ? a : b
  • Assignment expressions — e.g. x = y + 5

Example

int a = 5, b = 3;
int result = a + b * 2;   // arithmetic expression
int isGreater = a > b;    // relational expression
