Duplicating and Sharing Requests

Duplicating a Request

Duplicating a request creates an exact copy of an existing request, allowing you to quickly create a variation - such as testing a different parameter - without building the request from scratch.

Steps to Duplicate a Request

StepDescription
1. Right-click the RequestOpens a context menu with available options
2. Select DuplicateCreates a copy of the request in the same location
3. Rename if NeededUpdate the name to distinguish it from the original

Sharing Requests

Postman allows requests, folders, or entire collections to be shared with team members via a shared workspace, an exported file, or a generated link, making collaboration on API development straightforward.

Best Practices for Sharing

Adding clear descriptions, using consistent naming conventions, and organizing shared requests into well-labeled collections helps team members quickly understand and reuse each other's work.
