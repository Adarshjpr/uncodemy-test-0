1. Air Quality Prediction in Delhi City

Why it’s relevant in today's industry: Delhi’s air pollution is the best an,d also a well-documented set of challenges. Predicting all of the AQI (Air Quality Index) using different sets of historical data can help in policymaking at times.

Why it’s relevant: Delhi Metro handles millions daily, and analyzing passenger patterns can help optimize scheduling.

Dataset: DMRC annual reports, ticketing APIs (if accessible)

Tech Stack: Python programming language, SQL, Tableau

Extra Credit: Suggest your own set of crowd management strategies using AI-based forecasting that you have seen

Dataset: Government health department reports analysis

Tech Stack: Python, SQL, Tableau tools

Key Skills: Predictive modeling, data cleaning, and visualization tools.

Extra Credit: Build a dashboard showing all of the best possible real-time bed/ventilator availability.
